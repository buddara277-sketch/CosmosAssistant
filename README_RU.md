# Cosmos Assistant (первый каркас)

Пакет: `com.cosmosa27.cosmosassistant`

## Что уже заложено
- плавающий шар поверх приложений;
- перетаскивание шара;
- короткое нажатие открывает строку ввода;
- долгое удержание запускает распознавание русской речи, отпускание останавливает запись;
- базовые команды: открыть YouTube, ВКонтакте, будильник, музыкальный плеер, поиск в интернете, открыть экран набора номера.

## Как открыть
1. Установить Android Studio.
2. File → Open → выбрать папку `CosmosAssistant`.
3. Дождаться Gradle Sync.
4. Подключить Android-телефон с USB debugging.
5. Нажать Run.

## Первый запуск
1. Открыть Cosmos Assistant.
2. Разрешить микрофон и уведомления.
3. Нажать «Разрешить отображение поверх приложений».
4. В системных настройках разрешить отображение поверх других приложений.
5. Вернуться в приложение и нажать «Запустить / показать шар».
6. После появления шара можно закрыть экран приложения — сервис продолжит работу.

## Важные ограничения первого каркаса
- Голосовое распознавание зависит от установленного на телефоне сервиса распознавания речи и доступности сети.
- Команда «включи песню ...» пока не управляет поиском и воспроизведением внутри VK; сейчас запускается само приложение.
- Звонок пока открывает экран набора номера, а не звонит автоматически.
- Автоматизация интерфейсов сторонних приложений, управление ими и некоторые системные действия требуют отдельных интеграций и разрешений.
- Для Android 13+ и разных оболочек производителя могут потребоваться дополнительные разрешения на уведомления и автозапуск/работу в фоне.
- Это исходный каркас для первого запуска, не готовый релиз APK.
